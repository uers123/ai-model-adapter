# 数据治理与隔离

每个资源先建立清单：来源、许可证、用途、访问限制、文件大小、SHA-256、版本、核查日期和是否训练必需。缺失资源先报告，不自动下载。私有数据不得进入共享只读缓存。

强制分开：

- `train`：只用于学习；
- `validation`：用于自动调参；
- `final_blind_test`：只在最终验收使用。

按来源、对象或时间分组切分，检查重复样本、近似样本和元数据泄漏。最终测试集不得进入训练配置、提示词调优或模型选择。若盲测失败，继续训练前必须建立新的盲测集。

凭据、个人信息、Token、密码和签名 URL 不得出现在数据、日志、报告、YAML、JSONL 或导出物中。
