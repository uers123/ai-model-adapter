# 模型执行资格门槛

真实适配前，模型档案必须能回答：

- 官方仓库或官方模型页面是什么；
- 许可证、用途限制和发布边界是什么；
- 输入、输出和支持的模态是什么；
- 基座、架构和参数规模是什么；
- 依赖、Python、CUDA、操作系统和硬件要求是什么；
- 推理入口、训练/微调入口和数据格式是什么；
- 可独立复现的评估方法是什么；
- 已知限制和最近核查日期是什么。

处理规则：

1. 缺少训练入口，只允许推理分析和方案规划。
2. 缺少评估方法，不得声称达到目标。
3. 缺少许可证或用途不明，禁止发布、商业化和权重合并。
4. 资料冲突、过期或哈希不一致，状态为 `blocked`，先生成核查任务。
5. 目标超出模型能力边界时先阻止训练，再给出 RAG、数据、投影层或更换基座的替代路线。
